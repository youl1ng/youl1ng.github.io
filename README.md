# ooniverse.me

Owen Oo's portfolio. Next.js (App Router) + TypeScript + plain CSS, exported statically to GitHub Pages.

- `npm run dev`: local dev server
- `npm run build`: static export to `out/`
- Copy and data: `content/home.ts`
- Design tokens: `app/styles/tokens.css`

Pushing to `main` deploys through `.github/workflows/deploy.yml` (Pages source must be set to "GitHub Actions").
